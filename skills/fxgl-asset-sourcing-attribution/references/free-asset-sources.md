# Recommended Free Asset Sources

Use these as a **starting point**, not as a blanket approval. Always verify the license on the
specific asset page before importing anything into a project.

## Strong default sources

| Source | Typical asset types | Typical license posture | Notes |
|---|---|---|---|
| Kenney | sprites, UI, tiles, audio | CC0 | Strong default for broad game prototyping |
| OpenGameArt | sprites, tiles, portraits, audio | mixed | Filter aggressively; prefer CC0 or CC BY only |
| Freesound | SFX, ambience | mixed | Use only assets with explicit commercial-use-safe license |
| itch.io free asset packs | sprites, UI, audio | mixed | Accept only if the asset page clearly allows commercial use and modification |

## Capture this data from the source page

- asset title
- creator / publisher
- source URL
- download URL if available
- license name
- license URL
- any required attribution wording
- whether modification is allowed

## Skip immediately if you see

- no visible license
- "personal use only"
- non-commercial restriction
- no-derivatives restriction
- vague wording like "free to use" without legal terms
