# Placeholder Prompt Checklist

Use this checklist before generating temporary game art:

## Always define

- asset type
- gameplay role
- side-view / top-down / isometric perspective
- exact dimensions
- transparent background requirement
- readability target at gameplay scale

## For spritesheets

- frame count
- frame width and frame height
- single-row horizontal strip
- no padding between frames
- no labels or borders

## For tiles

- exact tile size
- whether seamless tiling is required
- clear distinction from neighboring tile types

## For UI icons

- icon meaning
- small-size readability
- centered composition

## Avoid

- photorealistic detail
- text and logos
- decorative frames unless required
- background scenes
- perspective drift
- copyrighted characters or named-artist mimicry
